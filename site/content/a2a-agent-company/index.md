## 프로젝트 개요

A2A Agent Company는 전북대학교 산학협력 캡스톤 프로젝트입니다. A2A 기반 다중 AI 에이전트가 협업하는 가상 소프트웨어 회사 개발을 목표로 합니다.

## 담당 역할

웹 애플리케이션 및 데모 개발을 담당하고 있습니다.

- React·Vite를 활용한 프론트엔드 개발
- FastAPI를 활용한 백엔드 개발
- API·데이터베이스·인증 연동

## 기술 스택

| 구분 | 사용 기술 |
| --- | --- |
| 프론트엔드 | React, Vite |
| 백엔드 | FastAPI |
| 데이터베이스 | SQLite |
| 인증 | JWT |

## 구현 기능 및 테스트 경험

웹 애플리케이션에서 다음 기능을 구현하고 테스트한 경험이 있습니다.

- 회원가입 및 로그인
- JWT 인증
- 전자문서 업로드
- 전자문서 목록 조회
- 전자문서 다운로드

## 통합 현황

에이전트 간 실제 연동과 전체 E2E 통합의 완료 여부는 확인되지 않았습니다.
